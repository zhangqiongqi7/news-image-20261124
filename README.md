One image summing up the world news of Tuesday 24 November 2026: Israel killing Hamas security chief Naim Abu Nahal in Gaza, a Russian strike on Zaporizhzhia, Germany becoming the first country to use Ukraine's Delta battlefield system, Baghdad moving to take over Kurdish oilfields, Ebola workers trapped in a hospital in Congo, and Trump awarding Rudy Giuliani the Medal of Freedom. The image is a newspaper-style summary drawn from that day's reporting (Al Jazeera, Reuters, UN News, AP News, Kyiv Independent).

## Run it

```sh
python3 main.py
```

`main.py` copies the image in `assets/news-20261124.png` to `/output/entry.png` (or `./output/entry.png` when run locally), byte-for-byte, so every run writes identical bytes. No network, no randomness, Python standard library only. The image itself was drawn by `tools/build_image.py`.
